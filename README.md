# Sphere Evcl

## Описание

Игровой прототип, в котором лабиринт и перемещение игрока проецируются на сферическую поверхность. Проект исследует необычную геометрию пространства и визуализацию клеточного мира не на плоскости, а на псевдо-3D сфере.

## Что реализовано

- генерация лабиринта;
- преобразование координат из сферических в экранные;
- отображение игрока на поверхности сферы;
- базовое перемещение по проходам.

## Стек

- Python
- pygame

## Запуск

```bash
pip install pygame
python sphere.py
```
